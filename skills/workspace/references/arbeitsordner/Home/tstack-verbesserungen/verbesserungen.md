# Tstack-Verbesserungen

Offene Punkte werden abgearbeitet und mit Datum und Commit abgehakt.

Format: `- [ ] <was auffällt / was besser werden soll>` – abgehakt: `- [x] ... (erledigt <datum>, <commit>)`
